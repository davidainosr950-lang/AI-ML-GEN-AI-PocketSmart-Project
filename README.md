## Project Basis
PocketSmart AI is a GenAI-powered budget and recommendation assistant covering:
- Home Interior Planning
- Party Budget Planning
- Jewelry Recommendations

The project document describes personalized, budget-aware recommendations using user budgets, preferences and optional images, with a backend/frontend architecture and integrations with multiple product/service platforms.
